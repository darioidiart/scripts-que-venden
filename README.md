# 📸 Organizador de Fotos para Mercado Libre

¿Tenés 200 fotos con nombres como IMG_2024.jpg? Este script las renombra a producto_001.jpg, las redimensiona y las deja listas para subir.

### Problema que resuelve
- Ahorra 2 horas de trabajo manual por publicación
- Fotos pesadas que ML rechaza -> las optimiza al 85% (de 4MB a 180KB)
- Nombres desordenados -> orden profesional para tu tienda

### Como usar
1. Poné tus fotos en una carpeta `fotos`
2. Corré: `python organizador_de_fotos.py ./fotos --prefijo zapatilla_nike`
3. Listo, fotos renombradas y optimizadas
