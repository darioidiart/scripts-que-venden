# Scripts que Venden

Automatizaciones en Python para e-commerce - Marcos Paz, MdQ

**Script 1 - Organizador de Fotos ML:** Renombra y optimiza 200 fotos en 10 seg. Pasa de 4MB a 180KB para que ML no te rechace las fotos.
Uso: `python organizador_de_fotos_ml.py ./fotos --prefijo zapatilla_nike`

**Script 2 - Scraper Precios ML:** Scrapea precios de Mercado Libre y genera Excel con promedio.
Uso: `python scraper_precios_ml.py`

### Como usar
1. Poné tus fotos en una carpeta `fotos`
2. Corré: `python organizador_de_fotos.py ./fotos --prefijo zapatilla_nike`
3. Listo, fotos renombradas y optimizadas

Instalacion: `pip install pillow requests beautifulsoup4 pandas openpyxl`
